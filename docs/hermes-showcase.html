Hermes Agent + Agent Reach

A CLI AI agent with eyes on the entire internet — search and read 15+ platforms from the terminal.

⚡ Tencent/Hermes CLI 🔭 agent-reach research layer 🐦 Live X posting via twitter-cli
AGENT

Hermes Agent

A terminal-native AI agent (by Nous Research) with tools for shell, files, web, browser, code, and subagents. Drives the desktop in the background, runs skills, and finishes jobs with real tool output.

REACH

Agent Reach

Gives the agent internet-scale research: YouTube, RSS, V2EX, Bilibili, any web page (Jina Reader), full-web semantic search (Exa), GitHub, and Twitter/X — 15 channels total.

X

Post from the CLI

Authenticated via twitter-cli with a Cookie-Editor export. Reads timelines, pulls tweets, and publishes new posts directly to a verified X account — no browser needed.
